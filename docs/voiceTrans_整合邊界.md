# `voiceTrans` 整合邊界

來源：<https://github.com/Weichen5700/voiceTrans>

目前只記錄為外部參考來源，不直接複製第三方原始碼，也不把它當成第一版的必要執行依賴。原因是整合前仍需確認其授權、相依套件、模型下載行為、輸入輸出格式及是否與本工具的「只輸出 WAV」邊界相容。

## 第一版處理方式

- 本專案保留自己的 `voice_lab` 服務與 UI。
- 先使用本專案的 FFmpeg 流程完成素材登記、裁切、清理與 WAV 輸出。
- 不在啟動時 clone、安裝或下載 `voiceTrans`。
- 後續若需要使用其功能，只能透過明確 adapter 接入，並把第三方執行檔／模型放在外部資料目錄。
- adapter 必須回傳統一的 `run_id`、輸入檔雜湊、輸出 WAV、退出碼與診斷 Log。
